# 個人Googleアカウントを許可リストで制御する

ATTではGoogle Workspaceを利用しておらず、利用者は個人のGmailアドレスを使用している。独自パスワードを管理せずに少人数のアクセスを制御するため、Cloudflare AccessをGoogleログインの入口として使用し、本システムのデータベースにあるメールアドレス許可リストと役割を認可の正本とする。システム担当が招待・ロール変更・無効化を管理する。Googleアカウントを持つだけでは利用できず、登録するアカウントでは2段階認証を有効にする。個人Googleアカウントの2段階認証状態をシステムから確認できない場合は、利用規程上の義務として本人確認を行う。
