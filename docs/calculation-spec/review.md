## 確認済みの定義

1. **前期間は確認済み**：月次は前の暦月、10日毎は前の区分（上旬1〜10日・中旬11〜20日・下旬21日〜月末）。例えば9月は8月全体、9月上旬は8月下旬と比較します。2026-09-07ユーザー確定。
2. **10日毎の費用は確認済み**：実経費は利用日で10日毎に表示。予算などの見込みコストは日割りせず、月次参考として別枠表示。月次集計しか持たない人件費も仮配賦しません。10日毎の予算差・全社利益は計算せず、事業利益は期間内実績で計算します（2026-09-07確認）。
3. **担当／案件段階で絞った予算・利益**：担当別予算・経費配賦の要件がないため、対応のないカードを対象外とします（2026-09-07確認）。

未請求／未入金は期末累積残高、経費総額は人件費を除く経費明細合計、時期未定のアクションは別枠とする定義も2026-09-07に確認済みです。

この確認で新機能を追加する必要はありません。要件の意図と違う箇所だけ修正し、確定した入力・期待値を実装テストへ渡します。

3か月・6か月は直前の同じ月数、会計年度は直前12か月（短縮年度は同じ月数）を比較する例を追加し、年越し・うるう年・年度変更を検算済み。具体的な両端日は仕様書の期間表を参照してください。
