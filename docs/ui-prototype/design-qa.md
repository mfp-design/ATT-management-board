- 総務は締め確定不可。経営者も未分類解消と仮の照合後に確定可能となり、理由付き解除で再締め待ちへ戻ることを確認。

## 発見して修正したが、再確認が必要な箇所

- 10日毎の全社利益のラベルを修正。
- 締め解除後も締め版の履歴を保持するよう変更。
- 競合の再確認済み状態をエラー文言で判定しないよう変更し、現在値と自分の変更を表示。
- 確認後にフォームの値を変えたら再確認が必要となるよう変更。
- 分類修正理由・回答者を明細へ表示。
- 閉じたスマートフォンのナビゲーションを非表示とし、フォーカス対象から除外。

これらの変更後のビルドは成功しましたが、操作を通した再確認は中断時点で終わっていません。

## 次回に解消する既知の課題

1. 取引先の同名登録が拒否される。要件に合わせ、候補を確認したうえで別取引先として登録できる画面に直す。
2. 一時アクセスの理由・期限は一部固定のサンプル表示。申請から役割切替・承認・取消までの一連の操作を確認する。
3. 複数月の集計でも予算・人件費欄が9月の固定サンプルである。期間に応じた表示を揃え、計算検証済みと誤認させない。
4. 締めの仮照合後に明細を変更した場合の再照合制御、監査履歴の役割別表示を要件と照合する。
5. スマートフォンのメニューのフォーカス移動・閉じた後の復帰、キーボード・ESC操作、色コントラストを確認する。
6. [画面一覧](screen-inventory.md)の不足画面を補い、CSV・印刷・支援コメント・各エラーの復帰動線を検証する。
