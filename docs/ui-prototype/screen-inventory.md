## 共通状態と端末

上部のプレビュー設定で通常・空・読込中・通信エラー・競合・利用不可などを切り替えます。確認ダイアログでは入力内容を確認し、確認後の変更には再確認を要求します。競合時は現在値と自分の変更を表示し、読み直し・再適用を選べます。

PCの主要入力と、スマートフォンの閲覧・フィルター・支援コメント・一時アクセス承認を中心に確認しました。メニューのフォーカス移動・ESC・復帰も確認済みです。確認範囲と証拠は [design-qa.md](design-qa.md) を参照してください。

## 画面案として簡略化している点

- 実際の認証・認可、永続化、通知、照合、排他制御は未接続です。プレビューの役割切替は本番機能ではありません。
- 財務サンプルは主に2026年9月、締め操作の対象月も9月です。過去時点の完全な復元・計算再現は未実装です。
- 分割予定は一括または2〜4回の入力例です。本実装の分割上限を決定したものではありません。
- 年度変更と復元は承認・適用待ちまでです。連携停止なども実環境へ反映しません。
- CSVファイル保存とOSの印刷／PDF保存は未確認です。CSV内容・コピー・印刷プレビューは確認しました。
- 全端末・全組合せを網羅した試験ではありません。二段階レビューと、本実装後の受入試験は別途必要です。
