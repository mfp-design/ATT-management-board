## 画面案の範囲

認証・DB・Slack・Cloudflareには接続していません。役割切替は表示設計の確認用であり、本番の認可を検証するものではありません。設定操作も架空状態の更新で、実サービスの開始・復元・課金・通知は行いません。UPSIDER PoCの設定とデータも変更しません。

財務実績は主に2026年9月、予算・人件費は2025年10月〜2026年9月のサンプルです。過去時点の完全なデータ再現、実DBの監査・締め・照合は本実装の対象です。分割予定の2〜4回は画面確認用の例で、業務上の上限を決めるものではありません。年度変更・バックアップ復元は承認後の適用待ちまでを表現しています。

CSVの内容表示・コピーと印刷プレビューを確認済みです。ブラウザーによるCSVファイル保存、OSの印刷・PDF保存は未確認です。

## 開発・ビルド

サーバー停止時はこのディレクトリで実行します。

```sh
npm ci
npm run dev -- --host 127.0.0.1 --port 4176 --strictPort
```

```sh
npm run build
```

ローカルビルドを確認済みです。単一JavaScriptチャンクが500 kBを超える警告は残っています。配信最適化・公開はこの画面確認の対象外です。テンプレート付属の配信用ファイルは保持しています。
